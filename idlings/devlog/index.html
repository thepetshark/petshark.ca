IdLings Dev Log

How IdLings was made, in the order it happened: from the Unity prototype I built alone to the App Store, five days of work in September 2026 with AI agents as my development team.

I ran them the way I ran human teams: workshops, mockups I reviewed round by round, a plan with a measurable definition of done, then the build, tested on a real iPhone. Claude Code agents wrote the code and the mockups under my direction, and OpenAI's Codex drew the new art. The ending stays a surprise: finish the game to see it.
