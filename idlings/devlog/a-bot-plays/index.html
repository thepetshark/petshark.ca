Testing and review 26 and 27 September

A bot plays the whole game

A bot that plays the real game code, start to finish, showed a flaw in the plan: time away from the game ran Mr Moody's clock down between visits, so no player could ever meet the definition of done. The agent changed the rule (the clock only runs while the game is open), recorded why, and moved on.

The same simulation set the pace: a player who never pays beats Mr Moody in round 7, after about eight and a half hours of play.

My part
The standing permission to make reversible calls like this one, as long as each is recorded.
The agents' part
Wrote the simulation, found the flaw, changed the rule and recorded why.
