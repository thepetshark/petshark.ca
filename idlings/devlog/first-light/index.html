Implementation 26 September

First light on the iPhone X

The first Godot build on the phone was just the name on grey. Getting even that far took a workaround: the current Xcode no longer pairs with an iPhone on iOS 16, so the agents installed and launched builds over USB with open-source tools, through a job runner on my Mac mini. Next came the first platform tests: the notification permission, then a test build for the store, Game Center and the review prompt.
