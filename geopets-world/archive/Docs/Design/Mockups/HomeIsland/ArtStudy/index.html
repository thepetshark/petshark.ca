Geo Pets World / Home art / September 16

A little village,
above the world.

Refined 2D art for the selected Village Green direction: warm limestone, teal and terracotta roofs, a quiet checkered lawn, and blue clouds over future land.

Separate artwork, together.

The scene combines the generated cutouts over the existing distant-world motion study. Buildings are shown near phone gameplay size.

This is an art preview, not a Unity scene. Each building currently has one illustrated angle; the four-view set, exact grid registration and mixed 3D rendering still need a runtime proof. Animals will be 3D models.

The island image studies the grass and wall treatment. It is not a seamless tile set or the final island geometry.
